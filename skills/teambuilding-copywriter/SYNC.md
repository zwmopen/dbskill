# 公开版同步说明

本目录是 `teambuilding-copywriter` 的**公开分享版**。

内部存在一个不公开的私有主版本，用于正式生产和维护完整规则。公开版只同步可安全公开的通用文案能力。

## 会同步
- 默认三版本
- 标题与正文规则
- 小红书高密度种草模板
- 字数限制
- U+2800 排版
- 小红书 / 抖音平台差异
- 事实门
- 可公开 Few-shot

## 不会同步
- 客户 / 公司 / 账号 / 订单
- 私有素材库
- 本地路径
- 内部自动化与生产流水线
- CDP / Codex / API 细节
- 私有验证记录与业务数据

## 当前默认输出
1. 小红书1｜自然攻略版
2. 小红书2｜高密度种草版
3. 抖音｜攻略版
