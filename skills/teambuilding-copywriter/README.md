# 团建文案 Skill｜公开版

一个面向 **小红书 + 抖音** 的团建/周边游文案 Skill。

默认一次输出：

1. 小红书自然攻略版
2. 小红书高密度种草版
3. 抖音安全攻略版

## 公开版 / 私有版

这套 Skill 分为两层：

- **公开版（你现在看到的）**：可直接分享、安装、复制，保留完整的通用文案能力。
- **私有版（内部主版本）**：包含更完整的生产系统、私有原料、自动化与内部业务规则，不公开。

私有版是主版本。以后私有版只要更新了**适合公开的文案规则**，会同步更新本目录；内部账号、客户、生产线、私有路径与业务数据不会同步。

公开版地址：
`https://github.com/zwmopen/dbskill/tree/main/skills/teambuilding-copywriter`


## 特点

- 小红书不做过度“安全阉割”，优先丰富、好搜、好收藏
- 高密度版支持参数卡、亮点、参考时间轴、玩法池、Emoji 与 SEO
- 抖音单独执行弱营销 / 去强商业处理
- 不编价格、车程、人数、客户案例、营业时间等事实
- 支持 U+2800 手机复制排版
- 高密度版默认控制在 1000 字符以内
