# 团建文案 Skill｜公开版

一个面向 **小红书 + 抖音** 的团建/周边游文案 Skill。

默认一次输出：

1. 小红书自然攻略版
2. 小红书高密度种草版
3. 抖音安全攻略版

## 特点

- 小红书不做过度“安全阉割”，优先丰富、好搜、好收藏
- 高密度版支持参数卡、亮点、参考时间轴、玩法池、Emoji 与 SEO
- 抖音单独执行弱营销 / 去强商业处理
- 不编价格、车程、人数、客户案例、营业时间等事实
- 支持 U+2800 手机复制排版
- 高密度版默认控制在 1000 字符以内

## 使用

把 `SKILL.md` 放进支持 Skill 的 AI 工具中，或者直接把内容作为系统提示词 / 项目规则使用。
