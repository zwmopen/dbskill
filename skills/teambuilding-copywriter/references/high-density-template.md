# 小红书2｜高密度种草版模板

## 定位

高密度种草版不是普通“攻略加长版”，而是：

**搜索标题 + 情绪第一屏 + 参数卡 + 亮点速览 + 参考时间轴 + 玩法池 + 组合建议 + SEO话题**

## 时间轴

原素材没有具体时刻时，可以根据真实项目自主规划参考时刻。

要求：
- 明确写“行程参考”
- 不冒充官方营业时间
- 不编交通耗时
- 不编景区班次
- 不把跨区域项目硬串在一起

## 玩法池

路线只执行部分核心项目，玩法池继续展示其余真实可选项。

建议：
- 核心路线：3—5项
- 玩法池：6—15项

## 长度

素材充足时：
- 目标：900—980字符
- 上限：1000字符

压缩优先级：
1. 删重复解释
2. 缩短同义判断
3. 精简提醒
4. 精简重复标签

不要优先删除真实项目名、参数卡、时间轴和强搜索词。

## 排版

只使用 U+2800：

`⠀`

不要同时使用独立圆点 `•` 做段落分隔。
